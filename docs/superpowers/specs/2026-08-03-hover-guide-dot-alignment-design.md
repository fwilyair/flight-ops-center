# 悬浮引导线与时间点对齐设计

## 目标

悬浮任务胶囊时，将绿色计划时间虚线整体向右校正，使虚线的中心轴穿过绿色圆点中心；紫色计算时间虚线采用相同规则，穿过紫色圆点中心。

## 范围

- 只调整悬浮状态下绿色、紫色纵向虚线的水平坐标。
- 保持圆点、胶囊、顶部时间标签、时间刻度和当前时间红线的位置不变。
- 保持虚线颜色、粗细、虚线样式、动画和垂直长度不变。

## 实现原则

虚线使用对应圆点在航班行时间轴中的实际坐标原点，而不是当前少计左侧卡片边框和间距的固定偏移。绿色与紫色虚线共享同一坐标校正规则，避免出现两套不同的偏移量。

## 验收标准

1. 悬浮普通任务胶囊时，绿色虚线在视觉上穿过绿色圆点中心。
2. 存在紫色计算点时，紫色虚线在视觉上穿过紫色圆点中心。
3. 顶部时间标签、胶囊、圆点及当前时间红线没有位移。
4. 横向滚动和切换时间刻度后，对齐关系仍然成立。
