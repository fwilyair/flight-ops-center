# 航班运行中心 Minimal Zine 海报设计

## 目标

为“航班运行中心”项目制作一张竖版 Minimal Zine Poster v0.1 风格海报。海报突出“精密运行与时间秩序”，用于项目传播与视觉展示，不承担产品功能说明。

## 核心概念

主题为“时间有航向”。一架飞机穿过时间刻度，将航班运行中心对节点、基线与分钟级进程的管理，压缩为一个安静而明确的视觉隐喻。

## 构图

- 画布为竖版 3:5，无边框、无场景化样机。
- 约 82% 画面保持为空白旧纸。
- 唯一视觉簇位于下方偏中位置，占画面约 15%。
- 视觉簇由一架横向飞机剪影、一段细时间尺、少量刻度与档案微文字组成。
- 不复刻产品 UI，不堆叠航班卡片、图表或仪表盘元素。

## 图像与材质

- 飞机使用单一、清晰的钴蓝色平面剪影。
- 时间尺和辅助文字使用低对比灰黑色。
- 全图呈现正面扫描的哑光旧纸：可见纸纤维、轻微斑驳、套印偏差与 risograph 颗粒。
- 不使用真实摄影、立体渲染、硬阴影、景深或电影灯光。

## 文字

主短句为：

> EVERY MINUTE HAS A HEADING.

使用小号衬线体、打字机体或等宽字体，贴近飞机或时间尺边缘排布。允许轻微错位与油墨渗化。可加入极少量半可读档案微文字，但不得形成长段落。

## 色彩

- 基底：暖米白旧纸。
- 辅助：灰黑色旧墨。
- 唯一高饱和色：充分饱和的钴蓝色 risograph 油墨。
- 钴蓝色约占全画布 1.5%—2.2%，并占视觉簇 20%—30%，缩略图尺寸下仍须清晰可见。

## 气质

安静、精密、克制、档案感、略带怀旧，接近日／韩独立杂志和实验编辑设计。观者应先感到“时间秩序”，随后才识别出飞机。

## 禁止项

- 满版场景、商业广告层级、醒目销售标题、CTA 或品牌锁定
- 干净数字 UI 白底、产品截图、仪表盘拼贴
- 霓虹、赛博朋克、3D、光泽纸张样机、硬阴影
- 卡通、动漫、可爱插画、时尚大片式戏剧化
- 多色装饰、贴纸堆叠、密集剪贴簿和长段清晰正文

## 验收标准

- 画面保持 70%—90% 纸张留白。
- 视觉簇占约 8%—25%，且不贴边。
- 只有一个明确视觉隐喻。
- 钴蓝锚点在缩略图中清晰可见且未被做旧效果冲淡。
- 海报呈平面扫描纸张效果，无三维空间感。
- 主短句基本可读，且没有额外的商业文案或水印。
