# 航班运行中心优化设计方案 (2026-04-13)

## 1. 目标
对航班运行中心进行视觉和交互优化，提升延误航班的识别效率、规范术语使用，并增强胶囊的可交互性。

## 2. 功能模块设计

### 2.1 延误航班视觉增强
- **识别逻辑**：航班对象中 `tags` 包含 `'D'` 即判别为延误航班。
- **视觉方案**：
    - **整体背景**：航班行左侧基础信息区域背景色改为淡淡粉色 (`rgba(255, 228, 230, 0.45)`)。
    - **状态同步**：当判定为延误时，状态 Badge (Status Badge) 固定显示为“延误”。
- **涉及组件**：`GanttRow.tsx`。

### 2.2 术语描述规范化
- **变更明细**：
    - “发送管控” $\rightarrow$ **“多级管控”**
    - “发送催办” $\rightarrow$ **“穿透管控”**
- **涉及组件**：`CapsuleDetailModal.tsx`。

### 2.3 胶囊右键交互系统
- **功能描述**：为时间轴上的胶囊（EventPill）增加右键交互菜单。
- **操作项**：**“可控/可消除”**。
- **效果表现**：
    - 被操作的胶囊将进入“弱化显示”状态。
    - 视觉表现：`opacity: 0.4`, `filter: grayscale(80%)`，并带有柔和的过渡动画。
- **技术实现**：
    - 在 `GanttRow.tsx` 中引入局部状态 `dimmedEventIds` (Set) 存储弱化状态。
    - 实现悬浮式的右键快捷菜单。
- **注意**：弱化状态为当前会话状态，不持久化到后端。

## 3. 技术变更

### 3.1 类型定义 (`types.ts`)
- `TimelineEvent` 接口增加可选属性 `isDimmed?: boolean`（视实现需要而定，目前暂定用局部 state 维护）。

### 3.2 组件逻辑 (`GanttRow.tsx`)
- 重构 `isDelay` 变量的生成逻辑。
- 在 `EventPill` 中绑定 `onContextMenu` 事件。
- 引入 `ContextMenu` 容器组件用于渲染右键菜单。

### 3.3 模态框 (`CapsuleDetailModal.tsx`)
- 全局替换按钮文案及相关提示词。

## 4. 验收标准
1. 点击带 'D' 标记的航班，左侧基础信息栏显示为粉色。
2. 打开胶囊详情弹窗，底部按钮显示为“多级管控”和“穿透管控”。
3. 对甘特图上的胶囊右键点击并选择“可控/可消除”，胶囊外观显著变淡。
